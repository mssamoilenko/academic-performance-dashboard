# Academic Performance Analytics Dashboard

### Power BI | DAX | Power Query | Data Visualization

## Project Overview

This educational data analytics project focuses on analyzing student academic performance using Microsoft Power BI.

The dashboard provides interactive visualizations to explore academic results across classes, subjects, assessment types, and time periods.

## Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization
- Data Modeling

## Dashboard Features

**1. Academic Performance Overview**
- Average Grade and assessment-specific KPI cards
- Performance comparison across subjects and classes
- Grade distribution by assessment type
- Geographic visualization of academic performance
- Monthly performance trends

**2. Class Performance**
- Interactive filters for classes, subjects, assessment types, and dates
- KPI measures for different assessment categories
- Comparative visualizations of academic performance

**3. Class Details**
- Drill-through functionality for detailed class-level analysis
- Student-level performance matrix
- Interactive navigation between report pages

**4. Month-over-Month Analysis**
- Previous Grade and Average Grade calculations
- Month-over-month percentage change using DAX
- Custom report tooltips for additional insights

## Project Outcome

Developed a multi-page Power BI report that supports interactive exploration of academic performance and helps identify patterns across subjects, classes, and time periods.
